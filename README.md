# Harsh Popat — Portfolio

A static portfolio for open-source contributions, software projects, and applied machine learning. [Live portfolio](https://harshpopat.vercel.app/)

## Local preview

Run `python -m http.server 8000` from the repository root and visit [localhost:8000](http://localhost:8000).

The home page is `index.html`. About, Open Source, Projects, Skills, Achievements, and Contact are standalone HTML pages. They share `style.css` and `script.js`, with no build step. Update the shared header links across all pages when adding or renaming a route.

Keep contribution status and evidence links current on `open-source.html`. When replacing `Harsh_Popat_Resume.pdf`, verify its project links and education details against the site.
